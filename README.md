# Galerie Dédal des Couleurs

Site vitrine one-page de la galerie de photographie d'art Dédal des Couleurs (Paris).

Projet universitaire — L3 Information-Communication, TP « Publier des contenus en ligne ».
Intégration en HTML5 et CSS3 (mobile-first) de la maquette Figma, avec un petit script JavaScript vanilla pour le menu mobile et le contrôle du formulaire.

## Arborescence

```
index.html     page unique du site
css/           feuille de style
js/            menu mobile et contrôle du formulaire
images/        images optimisées (WebP) et logo
fonts/         police Glacial Indifference (woff2, licence SIL OFL)
```
